# Docker Optimization Cheatsheet

## Quick Commands

### Using Makefile (Recommended)

```bash
# Install docker-slim
make install-slim

# Build and optimize all images automatically
make optimize-all

# Optimize individual services
make optimize-php
make optimize-nginx
make optimize-cron

# Show image sizes comparison
make show-sizes

# Run with slim images
make up-prod-slim
make down-prod-slim
make restart-prod-slim

# Run with regular images
make up-prod
make down-prod
make restart-prod
```

### Manual Commands

```bash
# Build multistage images
docker compose -f .docker/prod/docker-compose.yml build

# Run optimization script
./.docker/prod/optimize-images.sh

# Check sizes
docker images | grep dev-psyholodzhy-opencart
```

## One-Liner Full Optimization

```bash
make build-prod && make optimize-all && make show-sizes
```

## Typical Workflow

1. **Initial setup:**
   ```bash
   make install-slim
   ```

2. **Build and optimize:**
   ```bash
   make build-prod
   make optimize-all
   ```

3. **Check results:**
   ```bash
   make show-sizes
   ```

4. **Deploy slim images:**
   ```bash
   make up-prod-slim
   ```

5. **Test everything works**

6. **If issues, rollback:**
   ```bash
   make down-prod-slim
   make up-prod
   ```

## Cleanup

```bash
# Remove dangling images
docker image prune -f

# Remove stopped containers
docker container prune -f

# Remove unused volumes
docker volume prune -f

# Nuclear option (careful!)
docker system prune -af
```

## Troubleshooting

### Container won't start
```bash
docker logs <container_name>
docker inspect <container_name>
```

### Rebuild without cache
```bash
docker compose -f .docker/prod/docker-compose.yml build --no-cache
```

### Force recreate containers
```bash
docker compose -f .docker/prod/docker-compose.yml up -d --force-recreate
```
