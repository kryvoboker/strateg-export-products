# AttributeResource (Каталог -> Атрибути)

## Для чого ресурс
Керування атрибутами товарів: назва, статус, сортування, прив'язка до магазинів.

## Сторінки ресурсу
- `index` (`ListAttributes`): список атрибутів.
- `create` (`CreateAttribute`): створення атрибута.
- `edit` (`EditAttribute`): редагування атрибута.

Разом: **3 сторінки**.

## Як користуватись
1. Створіть/змініть атрибут:
- назва;
- sort order;
- магазини;
- активність.
2. У списку доступна масова прив'язка атрибутів до магазинів.
3. При create/update запускається `ProcessAttributeNameTranslationJob`.

## Фільтри і статуси
- Фільтр по магазину.
- Фільтр по статусу (`Активний` / `Неактивний`).

## Важливі повідомлення
- `Оберіть хоча б один магазин` для mass bind.
- Підсумок масової прив'язки (скільки атрибутів і магазинів оброблено).
