# ShopResource (Магазини)

## Для чого ресурс
Керування інтернет-магазинами, до яких прив'язуються товари/категорії/атрибути і куди йдуть API-запити.

## Сторінки ресурсу
- `index` (`ListShops`): список магазинів.
- `create` (`CreateShop`): створення магазину.
- `edit` (`EditShop`): редагування магазину.

Разом: **3 сторінки**.

## Як користуватись
Налаштуйте основні поля:
- `name`, `type`, `base_url`;
- API поля: `api_url`, `part_api_url_login`, `part_api_url_export_prods`, `api_token`;
- `options` (key-value налаштування);
- `is_active`.

## Важливе
- Якщо `api_url` не задано, в API-логіці використовується `base_url`.
- Для кожного магазину окремо можна керувати мовами через relation manager `Мови магазинів`.
